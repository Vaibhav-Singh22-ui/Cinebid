# Cinebid — Live Cinematic Movie Auction House

Cinebid is a high-stakes real-time multiplayer movie auction platform where producers compete to build their dream studio slate, bid on iconic blockbusters and award-winning films, and get evaluated by AI portfolio algorithms.

## Features
- **Real-Time Multiplayer Auctions**: WebSocket-powered live bidding, host-coordinated rounds, and countdown timers.
- **Interactive Community Chat**: In-room live chat with quick reaction emojis.
- **Smart AI Studio Portfolio Evaluation**: Multi-tier scoring analyzing Critical Acclaim (IMDb), Box Office ROI, Genre Synergy, and Capital Efficiency.
- **Rich Cinematic Design**: Luxury dark studio aesthetic with custom posters and golden accents.

## Tech Stack
- **Framework**: TanStack Start & React 19
- **Realtime & Database**: Supabase (PostgreSQL, Realtime WebSockets & Presence)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS Design System

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
